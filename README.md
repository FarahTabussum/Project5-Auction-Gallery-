# 🖼️ Auction Gallery

A modern and responsive auction platform built with **React**, **Vite**, and **Tailwind CSS**. The application allows users to browse active auction items, add products to a favorites list, calculate the total bid amount of selected items, and receive real-time notifications for their actions.

## 🌐 Live Demo

🔗 **Live Website:** [here](https://cooing-trail.surge.sh)!

## 🚀 Features

- Browse active auction items with a clean and responsive interface.
- Add auction items to a favorites list.
- Prevent duplicate items from being added to favorites.
- View the total bid amount of all selected items.
- Remove items from the favorites list.
- Display instant notifications using React Toastify.
- Fully responsive design for desktop, tablet, and mobile devices.
